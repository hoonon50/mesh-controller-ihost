OpenWRT MESH CONTROLLER PRO v6.0.6
==================================

OPRAVA UMISTENI HORNI HLAVICKY
- DATA a OBNOVENO jsou natvrdo ve stejnem hornim header clusteru jako:
  OpenWRT MESH CONTROLLER PRO / SONOFF iHost · DOCKER · IP.
- Poradi vlevo: NAZEV+SUBTITLE | iHOST | DATA | OBNOVENO.
- DOWNLOAD a UPLOAD zustavaji samostatne vpravo.
- DATA a OBNOVENO maji stejny ramecek, vysku, pozadi a radius jako iHOST.
- Spodni souhrnna lista zustava pouze:
  ONLINE ROUTERY | MESH SPOJE | KLIENTI | 5 GHz | 2.4 GHz | LAN
  a vsech 6 polozek je rovnomerne pres sirku.
- Zadne zmeny klientskych poctu, WAN, OWUT ani reboot manageru.
