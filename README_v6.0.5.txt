OpenWRT MESH CONTROLLER PRO v6.0.5
==================================

HORNÍ LIŠTA
- iHOST zůstává vedle názvu aplikace.
- Vedle iHOST jsou dvě nové stejně stylované dlaždice: DATA a OBNOVENO.
- DATA přebírá stávající hodnotu původní DATA dlaždice; význam hodnoty se nemění.
- OBNOVENO ukazuje čas aktuálního 5s live-topology backendového vzorku.
- DOWNLOAD a UPLOAD zůstávají vpravo v kompaktní šířce.

SOUHRNNÁ LIŠTA
- Původní DATA a OBNOVENO se v souhrnné liště skryjí.
- ONLINE ROUTERY / MESH SPOJE / KLIENTI / 5 GHz / 2.4 GHz / LAN se rovnoměrně rozloží přes celou šířku.
- LAN zůstává stabilizované pouze v RAM 45 s; Wi-Fi počty zůstávají live po 5 s.

BEZE ZMĚNY
- Klientská logika v6.0.4.
- MESH spoje/dBm/rychlosti 5 s.
- CPU/UPTIME 15 s.
- WAN 30 s, persistence na SD 1x za hodinu.
- Operation Manager, OWUT, rolling reboot a Wi-Fi AP policy beze změny.
